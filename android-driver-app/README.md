# SiteSeva Driver Android Preview

This is an installable Android WebView preview shell for the existing SiteSeva Driver portal.

- Application opens the SiteSeva registration page. Choose **Driver / ड्राइवर** as the account type.
- Dashboard opens the role-protected Driver Dashboard after the account is approved and the driver logs in.
- The app requires an internet connection and uses the verified SiteSeva Preview deployment.
- This is an internal debug APK for testing, not a Play Store release.
- No production credentials are bundled in the APK.
- Future native integrations (offline queue, camera capture, GPS/geofencing, push notifications) are not enabled in this preview.
